# AERE 361 Cheat Sheet 1

## C Types

| Type             | Size (bytes) | Range                                                        | Precision (decimals) |
| ---------------- | ------------ | ------------------------------------------------------------ | -------------------- |
| `char`           | 1            | $-128$ to $127$                                              |                      |
| `unsigned chat`  | 1            | $0$ to $255$                                                 |                      |
| `int`            | 2            | $-32,768$ to $32,767$ or $-2,147,483,648$ to $2,147,483,647$ |                      |
| `unsigned int`   | 2            | $0$ to $65,535$ or $0$ to $4,294,967,295$                    |                      |
| `short`          | 2            | $-32,768$ to $32,767$                                        |                      |
| `unsigned short` | 2            | $0$ to $65,535$                                              |                      |
| `long`           | 4            | $-2,147,483,648$ to $2,147,483,647$                          |                      |
| `unsigned long`  | 4            | $0$ to $4,294,967,295$                                       |                      |
| `float`          | 4            | $1.2\times10^{-38}$ to $3.4\times10^{38}$                    | $6$                  |
| `double`         | 8            | $2.3\times10^{-308}$ to $1.7\times10^{308}$                  | $15$                 |
| `long double`    | 8            | $3.4\times10^{-4932}$ to $1.1\times10^{4932}$                | $19$                 |

## `scanf` and `fscanf` Format Specifiers

| Symbol | Type           |
| ------ | -------------- |
| `%d`   | `int`          |
| `%f`   | `float`        |
| `%lf`  | `double`       |
| `%c`   | `char`         |
| `%s`   | String         |
| `%u`   | `unsigned int` |
| `%ld`  | `long`         |
| `%Lf`  | `long double`  |
