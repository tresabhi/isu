| ---------------- | ------------ | ------------------------------------------------------------ | -------------------- |
| `char`           | 1            | $-128$ to $127$                                              |                      |

| `short`          | 2            | $-32,768$ to $32,767$                                        |                      |
| `unsigned short` | 2            | $0$ to $65,535$                                              |                      |
| `long`           | 4            | $-2,147,483,648$ to $2,147,483,647$                          |                      |
| `unsigned long`  | 4            | $0$ to $4,294,967,295$                                       |                      |

| `long double`    | 8            | $3.4\times10^{-4932}$ to $1.1\times10^{4932}$                | $19$                 |

| ------ | -------------- |

| Symbol | Type                                            |
| ------ | ----------------------------------------------- |
| `r`    | Existing file for reading.                      |
| `w`    | New or existing (overwrite) file for writing.   |
| `a`    | New or existing file for appending.             |
| `r+`   | Existing file for reading and writing.          |
| `w+`   | New or existing file for reading and writing.   |
| `a+`   | New or existing file for reading and appending. |

## `main` Function Syntax

```c
int main(int argc, char** argv) { ... }
```

```c
int main(int argc, char* argv[]) {
  for (int i = 0; i < argc; i++) printf("%s\n", argv[i]);
  return 0;
}
```

## $\log$ Big-O Notation

Whenever a process does this kind of work:

$$
n + \frac{n}{2} + \frac{n}{4} + ...
$$

That ends up being:

$$
O(\log n)
$$

## `malloc`

Use `malloc` instead of `type symbol[n][m] = ...` to store value in heap instead of stack, allowing it to survive garbage collector at the end of a function. It's also just better for massive allocations:

```c
type *symbol = malloc(n * m * sizeof(type));
symbol = realloc(symbol, new_size);
free(symbol); // free the guy
```

## Array Initialization

```c
type symbol[size] = {1, 2, 3}; // explicit
// above, the unwritten slots will be 0
type symbol[] = {1, 2, 3}; // implicit
```
