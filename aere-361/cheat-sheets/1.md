File functions:

| Name      | Purpose                        |
| --------- | ------------------------------ |
| `fscanf`  | Read anything from file.       |
| `fprintf` | Write anything to file.        |
| `fgets`   | Read string from file.         |
| `fputs`   | Write string to file.          |
| `fread`   | Read data structure from file. |
| `fwrite`  | Write data structure to file.  |
| `fclose`  | Close file.                    |

Examples:

```c
// int x;
// FILE *file = fopen("file.name", "r+");
fscanf(file, "%d", &x);
fprintf(file, "x = %d\n", x);
// char line[size]
fgets(line, sizeof(line), file); // keeps \n
fputs("Hello, world!\n", file);

char *line = NULL;
size_t length = 0; // #include <ctype.h> and #define _GNU_SOURCE
getline(&line, &length, file);

int buffer[10];
FILE *file = fopen("data.bin", "rb"); // open as binary
fread(buffer, sizeof(int), 10, file); // raw binary
fwrite(buffer, sizeof(int), 10, file); // same here
fclose(file);
```

`fopen` modes

| Symbol | Type                                            |
| ------ | ----------------------------------------------- |
| `r`    | Existing file for reading.                      |
| `w`    | New or existing (overwrite) file for writing.   |
| `a`    | New or existing file for appending.             |
| `r+`   | Existing file for reading and writing.          |
| `w+`   | New or existing file for reading and writing.   |
| `a+`   | New or existing file for reading and appending. |

`main` function syntax

```c
int main(int argc, char** argv) { ... }
```

```c
int main(int argc, char* argv[]) {
  for (int i = 0; i < argc; i++) printf("%s\n", argv[i]);
  return 0;
}
```

Pointers:

```c
int iGetPointedTo = 67;
int* iPointTo = &iGetPointedTo;
int iEqualTo = *iPointTo;
*iPointTo = 69; // works
```

Use `malloc` instead of `type symbol[n][m] = ...` to store value in heap instead of stack, allowing it to survive garbage collector at the end of a function. It's also just better for massive allocations:

```c
type *symbol = malloc(n * m * sizeof(type));
symbol = realloc(symbol, new_size);
free(symbol); // free the guy
```

Array initialization:

```c
type symbol[5] = {1, 2, 3}; // explicit
// above, the unwritten slots will be 0
type symbol[] = {1, 2, 3}; // implicit
type symbol[size]; // dynamic
```

- `void*` points to type
- Parts of a for loop: initialization, condition, and increment
- The address of freed memory is called the **dangling pointer**

## Big-O Notation

Halving process which cuts search in half:

$$
n \rightarrow n/2 \rightarrow n/4 ... \implies O(\log n)
$$

Slower than a polynomial:

$$
O(e^n)
$$

## Bash

| Command | Arg.                                          | Purpose                                      |
| ------- | --------------------------------------------- | -------------------------------------------- |
| `wc`    | `-l`                                          | Counts number of lines                       |
| `sed`   | `s/replaced/bythis` file                      | Or you can pipe                              |
| `grep`  | `-r dir -e "string"`                          | You know what this does                      |
| `awk`   | `'pattern { action }' input-file`             | Text processor                               |
| `awk`   | `-F "," '{print NR ": " $1 "," $2}' file.csv` | Lists line index and grabs first two columns |

- Use `"$var name"` instead of `"$var name` as that's subject to **word splitting**
- Storing outputs: `symbol=$(command)`
- Shebang: `#!/bin/bash`
- User inputs: `input="#@"`
- Math mode: `symbol=$(( expression ))`
- `\[ ... \]` is the same as `$$ ... $$`
- Redirect **both** `stdout` and `stderror`: `source 2>&1 target`
- `<<` appends and `<` overwrite
