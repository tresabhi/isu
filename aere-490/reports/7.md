# AERE 490 Report 7

This week, I primarily focused on optimizing the rendering of my project in Blender, finalizing the render, and creating the posters. I was able to optimize the render time in Blender from an hour down to about a minute, thanks to the following changes:

- Enabled frustum culling, which probably doesn't help since there's no geometry behind the camera, but it's still a great thing to have on for simpler scenes
- Light clamping reduced any caustics from leaving behind light "fireflies"
- Increasing the noise threshold from `0.01` to `0.03` let Blender spend more time transporting light on low-light areas
- Fast GI approximations immediately kick in after the 2nd of my 32 bounces
- Embarrassingly, I had my rendered set to use my CPU which I promptly changed to the GPU
